# Фитнес Тренер

Приложение для учёта тренировок и оплат.

## Возможности
- 📋 Список клиентов
- 💰 Учёт оплат
- 🏋️ Проведённые тренировки
- 📊 Статистика
- 📊 Экспорт в Excel

## Технологии
- Kotlin
- Jetpack Compose
- Room Database
- KSP

## Установка
Скачайте APK из Releases или соберите в Android Studio.

# Фитнес Тренер

Приложение для учёта тренировок и оплат.

## Возможности
- 📋 Список клиентов
- Главный экран — «Клиенты». Экран «Сегодня» временно скрыт.
- Быстрое добавление клиента, оплаты и тренировки прямо из списка клиентов.
- Поиск клиентов и отдельный выбор порядка по алфавиту или диапазона оставшихся тренировок с ползунком «от–до».
- Карточка клиента: телефон, комментарии, дата рождения и автоматически рассчитанный возраст. Новые поля необязательны.
- Защита от повторного создания клиента с теми же именем и фамилией (без учёта регистра и лишних пробелов), в том числе при переименовании.
- 💰 Учёт оплат
- 🏋️ Проведённые тренировки
- 📊 Статистика
- Отдельные кнопки сортировки клиентов по алфавиту, числу тренировок и сумме оплат; повторное нажатие меняет направление.
- 📊 Экспорт в Excel

## Веб-версия и GitHub Pages

Сайт находится в отдельной папке `web/`. Изменения Kotlin-кода в `app/` сами по себе сайт не обновляют.
Веб-версия поддерживает тот же главный экран, быстрые действия и сортировку списков клиентов,
а также поля клиента, защиту от дублей и погашение долгов, описанные выше и ниже.
Дата рождения на сайте вводится через календарь браузера.

Для публикации отправьте изменения `web/` в ветку `master` (например, через merge pull request).
Workflow `Deploy GitHub Pages` проверит веб-логику и опубликует сайт. Его также можно запустить вручную,
выбрав ветку с нужными изменениями. Каждый deploy получает новую версию офлайн-кеша.
После успешной публикации закройте и снова откройте сайт, если он был открыт во время обновления.
Данные клиентов сохраняются в браузере; очищать данные сайта для обновления не требуется.

Проверка веб-логики: `node --test tests/web-ledger.test.mjs` из корня проекта (Node.js 22+).

## Установка
Скачайте APK из Releases или соберите в Android Studio.

В карточке клиента выберите «Ещё» → «Изменить карточку», чтобы заполнить новые поля.
Дата рождения вводится в формате ДД.ММ.ГГГГ. Новые поля сохраняются в резервных копиях;
старые копии поддерживаются. Обновление базы сохраняет существующих клиентов, оплаты и тренировки.

## Погашение тренировок в долг
В форме оплаты укажите «Всего оплачено занятий» и «Из них закрыть в долг».
По умолчанию новая оплата предлагает погасить текущий долг. Сначала закрываются старые
тренировки; оставшиеся оплаченные занятия поступают в пакет. Например, 5 оплаченных
занятий и 2 погашения дают 3 занятия в пакете. При погашении новая тренировка не создаётся.

Погашенные занятия сохраняют отметку «Была в долг · оплачена». Текущий долг в списке,
карточке и статистике включает только непогашенные занятия. При изменении оплаты
связи пересчитываются, при удалении оплаты её долги снова становятся непогашенными.
Если удалить погашенную тренировку, занятие вернётся в пакет.

Старые оплаты автоматически не погашают долг. Откройте такую оплату, укажите фактическое
число оплаченных занятий (вместо прежнего 0) и количество закрываемых долгов.
Оплата с 0 занятий меняет только сумму. Прежнее поведение оплаты одного занятия без
погашения долга сохранено: на дату оплаты автоматически создаётся тренировка.
